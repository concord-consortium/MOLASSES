Contents of the `hawaii` folder:
- `dem.asc`: symbolic link for Lis Gallant's DEM file to simplify typing
- `dem.grd`: symbolic link for Chuck Connor's DEM file to simplify typing
- `MaunaLoa_30m_UTM5N.asc`: DEM file for big island of Hawaii from Lis Gallant
- `MaunaLoaEast_wgs84z5_20m.grd`: DEM file for big island of Hawaii from Chuck Connor; not recognized by our local gdal libraries (?).
- `molasses.conf`: configuration file with "small" eruption parameters from Chuck Connor
- `vents.utm`: configuration file with "small" eruption location from Chuck Connor
